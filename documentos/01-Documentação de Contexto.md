# Introdução
<strong>1.1 Introdução </strong>
<p>Com a crescente digitalização dos serviços bancários, muitos usuários enfrentam dificuldades em se adaptar às plataformas online, especialmente quando novos sistemas são implementados. Esse desafio é particularmente significativo para pessoas idosas e usuários com necessidades especiais, que frequentemente encontram barreiras de usabilidade. Além disso, profissionais de TI bancário lidam com sistemas complexos e desatualizados, tornando a manutenção e atualização dos serviços uma tarefa árdua. A criação de uma interface de simulação para um sistema bancário se apresenta como uma solução eficaz para esses desafios, permitindo que os usuários testem e se familiarizem com as funcionalidades em um ambiente seguro e controlado.</p>

## Problema

<p> O principal problema abordado pelo projeto Easybank é a dificuldade que diferentes grupos sociais possuem ao usar os aplicativos bancários da atualidade. Em muitos casos, pessoas não se sentem seguras para realizar transações online, e idosos e indivíduos com necessidades especiais enfrentam desafios significativos por conta da baixa acessibilidade. Além disso, há a ausência de um ambiente seguro para simulação e treinamento - agravando ainda mais o problema citado - que resulta uma experiência negativa para o usuário final e em maiores custos de manutenção para as instituições financeiras. </p>

## Objetivos

<p> O objetivo geral do projeto feito pelo Easybank é desenvolver uma interface de simulação para um sistema bancário, que permitirá aos usuários experimentar todas as funcionalidades de forma segura. A simulação ajudará os clientes a se acostumarem com as operações bancárias online, reduzindo também o risco de erros e aumentando a confiança no uso do serviço oferecido. 
Além disso, como objetivo específico, para os profissionais de TI, a interface de simulação fornecerá uma plataforma para testar novas atualizações e funcionalidades sem comprometer o sistema real. Já para pessoas idosas e com necessidades especiais, a interface será projetada para ser acessível e inclusiva. </p>


## Justificativa

A implementação de uma interface de simulação é crucial para mitigar os desafios enfrentados por diferentes perfis de usuários ao interagir com sistemas bancários. Estudos mostram que uma parcela significativa de clientes bancários reluta em usar serviços online devido à falta de familiaridade e medo de cometer erros. Além disso, a acessibilidade é uma preocupação crescente à medida que a população envelhece e as necessidades especiais são mais reconhecidas. Ao criar uma plataforma de simulação, o projeto visa melhorar a experiência do usuário, aumentar a confiança e reduzir o tempo e custo de suporte técnico.

## Público-Alvo

Clientes Bancários Gerais: Pessoas que utilizam serviços bancários regularmente para transações do dia a dia, como pagamentos, transferências e gerenciamento de contas.

Idosos: Pessoas de idade avançada que podem ter dificuldades com tecnologia, buscando uma experiência mais intuitiva e acessível.

Usuários com Deficiências: Pessoas com necessidades especiais que enfrentam barreiras de acessibilidade em plataformas tradicionais e precisam de uma interface adaptada.
